# Adoption plan record

The authoritative mapped-adoption completion/dependency record is
[`machine-readable/plan.json`](../machine-readable/plan.json). It describes
completed dependencies and their bounded acceptance evidence. Any future item
must remain a plan, not a task ledger, lease, receipt, assignment, or permission
source.

## Product implementation navigation

Use [the integrated initial-product path](../../docs/implementation/initial-product.md)
and its sole scoped owner [ADR-0008](../../docs/decisions/ADR-0008-integrated-initial-product-and-effective-plan.md).
The dossier adoption plan remains workspace-adoption history, not a product ledger.
