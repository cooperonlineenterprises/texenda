# Adoption RAIDQ

[`machine-readable/raidq.json`](../machine-readable/raidq.json) owns consolidated
workspace/adoption risks, assumptions, issues, dependencies, and questions. It
does not duplicate product gates or create work-package status.

[Workspace retention](workspace-retention.json) owns dependency-based local
retention classes and preserves receipt/recovery dependencies. It authorizes no
cleanup and does not supply product privacy/retention qualification.
